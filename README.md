## 📌 Project Overview
ST NeuraNote is a Generative AI-powered document intelligence tool designed to eliminate information silos. It allows teams to upload unstructured meeting artifacts (handwritten notes, images, digital text, and folders) and instantly transforms them into structured, searchable, and digitized records. 

## 🚀 Key Features
* **Multi-Modal Input:** Accepts images (via OCR), raw text, and batch folder uploads.
* **High-Speed LLM Inference:** Connects to LLM APIs to contextually understand, summarize, and structure raw meeting logs in near real-time.
* **Unified Knowledge Base:** Consolidates fragmented data into a centralized, easily retrievable digital format.
* **Interactive UI:** Built with Streamlit for a seamless, responsive user experience.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit
* **Backend:** Python
* **AI/ML:** LLM APIs (OpenAI/Gemini), Optical Character Recognition (OCR) 
* **Data Processing:** Pandas, Regular Expressions (Regex)
